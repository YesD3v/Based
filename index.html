What's inside

Built to actually help

Clean Overlays

Crisp, configurable HUD overlays and info panels that stay out of your way until you need them.

Quality of Life

A toolkit of QoL tweaks and keybinds that make everyday play smoother without changing how the game feels.

Visual Debugging

Advanced visual debugging tools to inspect, trace and understand what the world is doing in real time.

ImGui Interface

Fast, native-feel ImGui menus — resize, drag and configure every module on the fly.

Accounts & Cosmetics

Built-in account handling and cosmetic support, all wired into one tidy interface.

Lightweight & Fast

A single Fabric jar. Drop it in your mods folder and go — no launchers, no bloat, no DRM.

100% UN-OBFUSCATED

Nothing to hide.

Most clients ship a scrambled, obfuscated jar you're told to just trust. Based is not one of them.

The build is shipped clean and readable — real class names, real packages, no junk, no hidden payloads. Decompile it, read it, learn from it. What you run is exactly what you see.

Because YesDev is goated and doesn't hide code behind a proguard wall.

Install

Three steps. One jar.

Get Fabric

Install the Fabric Loader (≥ 0.16) and Fabric API for Minecraft 1.21.11 on Java 21+.

Drop the jar

Download the latest Based Client jar and place it in your .minecraft/mods folder.

Launch

Start the game on the Fabric profile. The crown's live — open the menu and you're based.
