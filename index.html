What it is

Stays out
of your way

Based Client is a standalone Minecraft Fabric mod built around three things: clean overlays, quality-of-life tooling, and advanced visual debugging.

It ships as a single jar. Drop it in your mods folder and launch — no separate launcher, no account wall, no DRM, nothing running in the background.

01

Clean Overlays

Configurable HUD panels and readouts that stay legible and quiet until the moment you need them.

02

Quality of Life

Small tweaks and keybinds that smooth out everyday play without changing how the game feels.

03

Visual Debugging

Inspect, trace and visualise what the world is doing in real time — detail you usually can't see.

04

ImGui Interface

Fast, native-feel menus. Drag, resize and configure every module live, with no clutter to fight.

05

Accounts & Cosmetics

Built-in account handling and cosmetic support, wired cleanly into one interface.

Open · Not obfuscated
What you run is
exactly what you read

Most clients ship a scrambled, obfuscated jar and ask you to just trust it. Based doesn't. The build is clean and readable — real class names, real packages, no ProGuard wall, no hidden payloads. Decompile it, read it, learn from it. Because YesDev is goated.

Install

Three steps. One jar.

1

Get Fabric

Install Fabric Loader (≥ 0.16) and Fabric API for Minecraft 1.21.11 on Java 21+.

2

Drop the Jar

Place the Based Client jar into your .minecraft/mods folder.

3

Launch

Start Minecraft on the Fabric profile. Open the menu — you're set.
