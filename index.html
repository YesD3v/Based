Open · Not obfuscated

What you run is
exactly what you read

Most clients ship a scrambled jar and ask you to trust it. Based doesn't - real class names, real packages, no obfuscation wall. Decompile it, read it, learn from it.

net/basedclient/client/BasedClientMod.java
package net.basedclient.client;

public class BasedClientMod {
    public void onInitializeClient() {
        Modules.loadAll();   // all 135
        Hud.attach();
        // clear names - what you read is what runs
    }
}
